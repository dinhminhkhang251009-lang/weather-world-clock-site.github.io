# Weather & World Clock

Trang web xem thời tiết và giờ toàn cầu, kèm bản đồ và dự báo 7 ngày.

## Triển khai lên GitHub Pages

1. Tạo repo mới trên GitHub.
2. Sao chép URL remote và chạy:
   ```bash
git remote add origin <url>
git push -u origin main
```
3. Trong cài đặt repo, bật GitHub Pages: branch `main`, thư mục `/`.
4. Truy cập `https://<username>.github.io/<repo>/`.
